# 通过已有图谱导航

`scripts/navigate.py` 读取现有 Pro 图谱，不重新抽取、不改变实体身份，也不把导航历史写回来源。所有入口可离线使用。旧 `query_global.py` 保留，便于复现已有评测。

## 从词汇到原文

1. `discover --query "英文概念或代码名"` 返回实际实体、命名空间、种类和稳定 ID。匹配只使用名称与命名空间分词，按精确名称、词项重合数排序；不做模型名称合并，不使用文档 BM25。可用 `--kind`、`--namespace` 缩小目录，或用空查询与 `--offset` 浏览。
2. `inspect --entity <ID>` 返回直接相邻卡片的关系分布、标题及来源行号。关系用于帮助理解，不默认硬过滤。标题是候选概括，不是已核实答案。
3. `neighbors --entity <ID> [--card <card_id>]` 返回在同一卡片中出现的其它实体及经过的卡片 ID。可以选择邻居再次 `inspect`，逐步探索；不自动扩展整个图，也不宣称最短路径或物理依赖推理。
4. `source --path <path> --start <line> [--end <line>]` 读取原文。每次验证哈希；整行容纳不下时保留 `next_line`，增大预算或续读，不静默丢弃后续原文。涉及定义、变量赋值、include 或脚本顺序时，需要沿实际原文继续阅读，不以局部引句代替完整上下文。

所有命令支持 `--budget`，按序列化 JSON 的 Unicode 字符精确计算，包含来源和导航元数据；默认 3000。目录支持 `--limit`、`--offset`，返回 `next_offset`。预算过小而首项放不下时明确返回状态，不能把空列表当成没有证据。

`kind` 可选 `model`、`solver`、`utility`、`parameter`、`field`、`file`、`case`、`concept`；不确定时省略，`available_kinds` 给出当前范围可用种类。不合法的种类会报错，而不是伪装成无证据。原文返回 `total_lines`，请求终点超过文件末尾时读到末尾，起点超出文件仍报错。

`--case` 必须是目录清单中的完整案例路径；范围内可关联手册，但不会返回其它案例的卡片。各次调用应保持相同范围。`--scope manual` 或 `--scope tutorial` 可进一步限制来源。不同命名空间的同名实体仍保持独立 ID；不能用标签代替 ID 自动选中某个同名模型。

## 能力边界

当前邻域来自“实体—来源卡片—实体”的共现结构。它有助于找邻近概念和文件，但卡片关系没有变成实体间的因果边，也没有补建完整修改依赖。若卡片摘要含有引用片段之外的信息，必须打开来源核对；不把候选摘要用于自动修改。

维护语料和增量构建仍遵循 [全局图谱说明](global-graph.md)。来源变化后须重建索引，不能在旧图上继续使用失效定位。导航评测与运行记录位于 skill 外，不能回写语料以改善测试成绩。
