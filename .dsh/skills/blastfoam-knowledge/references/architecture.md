# 构建与图谱说明

## 已实现范围

首版采用确定性抽取：OpenFOAM 字典结构、值的原始表达式、README 文本、脚本命令出现顺序、可解析的相对 include、手册原书书签层级与页证据。配置值与手册小节按名称连接；同名时按明确 selector 的作用域筛选，仍不唯一则保留歧义诊断。没有调用 LLM 自动抽取全书语义，未将公式转录确认为结构化物理事实。

图谱是带属性的有向多关系图，采用 JSON 保存，查询端用邻接表扩展，无需数据库服务器。主要节点是 case、file、configuration、script_step、source_span、manual_section、manual_page。配置实例使用文件＋完整字典路径标识，重复键保留序号；原始值与是否含未求值表达式分别存储。

主要关系：CONTAINS、HAS_SPAN、DEFINED_IN、HAS_SECTION、DOCUMENTED_ON、REFERS_TO_DEFINITION、INCLUDES、HAS_STEP、NEXT_IN_SCRIPT、HAS_STAGE_DIRECTORY、CONFLICTS_WITH。关系绑定来源证据及抽取状态。没有把命令顺序升级成条件无关的依赖，也没有把手册与教程的名称连接升级成物理适用性证明。

手册书签是章节定位，不是精确的段落语义边界；跨页与同页章节可能重叠。页级正文保留完整上下文，必要时读 region 图片。复杂列表中的内嵌字典目前保留为整个值，尚未逐列表项拆分。STL/OBJ 等几何文件作为资源节点保留，不把坐标数据块作为自然语言文档检索。

## 更新与发布

`index/current.json` 指向 `index/releases/<snapshot>/`，其中包含 graph.json、documents.json 和 manifest.json。清单固定全部语料文件哈希（包括 PDF 与图片），构建代码与术语文件也参与版本标识。缓存位于 `index/cache/`，按抽取工具版本、相对路径和内容哈希复用教程抽取产物，可删除并重新生成。

每次构建重新组装图与文本索引，因此增加/删除案例、修改 include 目标、改变配置都会更新全图连接，未变化的教程文件不重新解析。手册目前为确定性的书签与页组装，每次变化构建会重组，不进行昂贵的模型再抽取。无变化时返回 unchanged。重建在临时目录完成，检查通过后原子切换 current 指针；失败保留原指针。若源语料已改变，旧版本查询会拒绝混用，而不是声称旧语料仍可用。历史索引不包含历史语料副本，完整回溯需另存对应 corpus 快照。

为移植和缓存一致性，运行时路径均相对 skill；也可以使用 `--corpus` 和 `--index` 指向隔离的测试副本。并发修改语料不受支持，发布前会再次扫描哈希检查构建期间是否改变。多个构建者应串行执行，当前没有跨进程构建锁。

已知目录别名 `setRefinedFields/internalDetonation_withObstacleAndGlass` 仅在内容与规范案例完全相同时去重；任一目录改变后分别建模，删除规范案例不会丢弃仍存在的别名目录内容。其他未知的同内容案例不会自动视为同一身份。原生目录软链接的通用导入与身份迁移尚未实现，维护时需先生成无循环的可移植语料快照。

## 检索与限制

基于 BM25 形式的词项评分，支持标识符与 camelCase 分词；`terms.json` 是用于召回的中英文领域关联词表，并非严格同义词或知识事实。案例排序优先场景 README，避免大案例仅凭文件数量占优；随后返回匹配原文与冲突。手册使用书签上下文减少同名模型混淆，目录/参考文献页降低排序权重。

图谱扩展从命中片段及覆盖的配置项出发，最多走三条关系。允许配置→定义→页、冲突→实际配置→定义→页、脚本→工具→定义→页等有类型的路径。要求示例或指定案例时才允许手册→定义→配置的逆向查询；只在请求流程、命中 Allrun 或步骤节点时扩展脚本步骤。案例范围约束贯穿所有路径。

v1.1 的 `ranking.py` 将图谱与文本候选合并后按文件去重，总输出不超过 limit。保留最强的前半预算文本文件，其余候选使用归一化文本分数加最多 0.5 倍路径支持排序。路径每跳衰减；冲突与定义到页面的定位不额外衰减；逆向实例关系按唯一邻居数降权。同一候选只取最大路径支持，不累计重复关系或路径数。因此打乱边顺序、重复相同边不应改变结果。没有用开发集拟合权重，也未增加案例/题目专属规则。词表与语料保持首版版本。

每个入选的图谱证据记录起点文档、起点节点、定位及完整路径，区分词项得分与图谱支持。`related_evidence` 是 results 子集；文档模式不再采用“8 个文本结果后追加最先遍历到的 8 个节点”。旧接口将 related_evidence 再次拼接会造成重复，需按新契约读取。案例选择模式的候选排名沿用原逻辑，附加证据仍独立输出。

当前不具备完整的修改影响推理、自由形式图路径规划、语义向量召回或全书参数约束校验。后续语义事实与依赖的证据、条件和覆盖要求见 semantic-contract.md，不能以宽泛关键词规则生成硬性依赖。

查询每次校验全语料哈希，偏重可追溯性而非最低延迟。图谱查得的信息由调用 skill 的智能体解释，脚本输出证据，不自动生成无来源的自然语言答案。

## 验证与评测

`scripts/validate.py` 校验版本、节点/关系、索引证据和语料哈希。项目 `tests/test_knowledge_skill.py` 使用临时语料测试增删改、缓存复用、构建失败、干净全量重建一致性、字典作用域、定义扩展及来源路径边界。

检索开发集独立位于工作区 `dataset/retrieval/blastfoam_v1/`，只由评测脚本读取，不属于 skill 索引输入。开发集的种子标注尚未独立复核；命中率不是完整语料 Recall，更不是最终回答正确率。正式评测需补标、封存独立测试题，并与原检索方法对比。
