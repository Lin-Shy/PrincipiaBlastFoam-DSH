# 紧凑原文证据包

实现位于 `scripts/evidence_bundle.py`，属于本 skill 的离线构建和检索能力。目标是减少智能体逐次搜索、查看卡片、再读文件的调用，把可确定的原文收集工作交给程序。是否降低实际 API Token、是否保持答案质量，需要分别评测，不能从压缩比推导。

## 构建

读取已发布的 `index/current.json` 结构快照、原文和术语表，生成独立派生图，不更改原有结构索引或 `semantic/global` 候选卡片。实现和语料都不读取 `dataset/` 标注、题目 ID 或结果。

- 配置节点按字典作用域组织。函数对象按 `functions/<对象>` 聚合，保留该对象的 `type`、采样位置、`fields` 和输出控制；主场控制另存，不与函数输出混同。
- 配置片段、README 和脚本长段按完整行拆分；手册复用新版结构索引中的章节证据单元，公式、表格和代码块保持完整。节点保留文件路径、作用域、来源行号、案例归属；文件 SHA-256 保存在清单中。
- `REFERS_TO_DEFINITION`：复用结构图中名称与作用域匹配的手册定位，仍需核对原文上下文。
- `INCLUDES`、`CONFLICTS_WITH`：复用结构图中已解析的包含和文本冲突连接。
- `CASE_SCRIPT_CONTEXT`：同一案例的运行脚本上下文，不表示无条件执行依赖。
- `UTILITY_INPUT_CANDIDATE`：脚本明确出现工具命令，且案例中存在其惯例命名的字典。它仅是输入文件候选；带 `-dict`、`-region` 或变量的命令不作此连接。脚本中的工作目录变化、分支与运行结果未求值，不能据此确认实际执行。
- `SEPARATE_OUTPUT_CONTROLS`：函数对象与同文件顶层输出控制属于不同作用域。连接用于同时提供依据，不能推出启用探针就会停止全场输出。

新增构建不调用模型 API；这是新增配置层的成本，不代表整个项目过去的语义抽取免费。这里也没有重做昂贵的全书语义抽取。派生快照固定构建代码、原始结构快照、术语、语料和图内容；修改或删除来源、变更术语、切换结构快照或修改代码后拒绝读取旧派生图。

```bash
python scripts/evidence_bundle.py build --index <外部归档目录>/derived-graph.json
python scripts/evidence_bundle.py search --index <外部归档目录>/derived-graph.json --query "<原需求及忠实英文技术表达>" --budget 6000 --audit <外部归档目录>/query-audit.json
```

## 搜索与预算

三个策略共用证据单元、词法打分、候选案例定位、去重和打包逻辑：

| 策略 | 扩展方式 |
|---|---|
| `text` | 仅按词法相关性选择来源片段 |
| `files` | 在相同候选案例中补充配置片段，控制普通案例范围扩展的收益 |
| `graph` | 依据配置角色和上述类型关系扩展，最多两跳，保留选择路径用于审阅 |

候选最多两个；明确指定案例时只保留该案例和手册。所有策略采用相同范围约束。角色识别来自通用需求词和实际配置作用域，是检索线索，不是经过验证的物理需求分解。图谱策略既增加角色排序也增加关系扩展，因此三组比较检验这套组合；若需单独归因于某种关系，需另作消融。

默认上限为6,000个Unicode字符，可设置1,000–24,000。上限约束整个紧凑JSON，包括来源表和提示；不是 Token 上限。每个片段保持原文与完整行。重叠行以及不同文件中完全相同的内容不重复装入。过长单元可以不装入；没有装入不表示原文没有该知识，也不代表需求已完整覆盖。

返回 `sources` 和 `evidence`，直接供智能体解释，无需为每个片段再进行一次原文读取。`scope` 说明字典位置，`via` 是选择理由；完整连接证据在可选 `--audit` 中，不反复注入答案上下文。最终引用以 `sources` 中实际路径和片段行号为准。

## 使用限制与评测

自然语言含糊、术语不匹配或词表未覆盖时，首个候选可能偏离。应忠实改写查询并保留不确定性；不得为了命中而虚构条件。该入口不能保证找到所有可用案例，也不能根据检索未命中宣布某功能不存在。

字典解析不执行宏、include指令、脚本或仿真；完整行不等于语义完整。`.orig` 仍是模板内容，字段声明不是活跃网格的边界证明。构造完整修改方案需核验原文中的生成、覆盖和执行过程。

评测适配器位于项目 `experiments/retrieval_method/evaluate_evidence_bundle.py`；模型响应、派生索引、逐题证据和报告归档到项目外的毕业实验结果目录。首轮采用共享查询改写、一次证据包和一次最终回答；各组按独立运行口径完整计入查询改写成本。旧实验与新实验同时改变了预算、上下文组织和提示，不能把二者 Token 差额归为图谱单独收益。
