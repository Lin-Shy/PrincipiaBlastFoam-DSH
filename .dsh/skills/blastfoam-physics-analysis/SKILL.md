# blastFoam 物理分析

2026-11-23执行边界：agent和源码开发在Linux，Windows仅SSH控制；所有仿真及计算型后处理必须通过yhbatch在超算实际分配节点执行，不能在控制机/登录节点运行。大结果留超算，本机仅配置与有界控制记录。当前仅迁移维护，不启动实验。

新建仿真或物理模型发生实质变化时，首先使用本 Skill。

## 操作步骤

1. 把需求规范为几何、维数、材料、炸药/源项、初始状态、边界、目标观测量以及时间/长度尺度。
2. 使用基础文件读取/搜索工具查阅任务许可的公开教程与手册原文，记录版本与实际路径。
3. 用 `--mode cases` 查找候选教程，再用 `--case` 限定配置查询、用 `--mode manual` 核对模型定义；选择前检查原始文件与适用条件。检索分数不等同于模型适用性。
4. 明确哪些物理与数值特征可以原样迁移，哪些必须修改。
5. 定义稳定性风险、预期定性行为、定量检查，以及能够推翻当前配置方案的证据。

## 输出

写入或返回 `physics_report.md` 交接内容，其中包含所选教程路径、检索证据、假设、方程/模型、边界与初始条件、数值方案、未决问题和验收标准。本阶段不得编辑算例或执行 solver。
