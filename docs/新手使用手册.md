# DSH Linux使用入口

2026-11-23：Windows只用SSH连接个人Linux服务器下达命令和查看；DSH源码开发、Git、依赖和agent进程在Linux的agent账号下运行。不要先在Windows启动DSH再路由工具。

在Linux加载开发工作区environment.sh，可用dsh-dev --profile headless --dump-config做无模型配置检查。已部署controller运行实例与开发源码分开，源码变更须显式构建部署并保留版本身份。

真实模型单算例和Web基本交互已验收，本次更新执行位置规则，不启动批量实验。后续模型由API服务推理，不在控制机部署本地大模型。轻量建网、checkMesh、小规模预处理与分析可在独立Linux本地执行，先核对软件及CPU/内存/磁盘余量并设置合适的超时和输出限制；大型网格、重求解和大型后处理经yhbatch。公共登录节点只做轻量提交、查询和传输。大结果留超算，Linux仅保留配置、源码、依赖、有界日志与结果路径/哈希/摘要。agent直接使用凭据，不要求root代操作。
