# 第3章Linux插件与工具

当前源码开发与agent运行在Linux，Windows仅通过SSH控制。默认专业系统已离线验证pressure_window、convert_volume_rates、interval_coverage、latest_attempt_events四项工具及三份技能；旧五专家bundle是可选历史实现，不能据文件存在宣称已全部加载。

领域MCP为mcp_servers.principia_domain.server，提供算例配置、字典编辑与证据操作，本机仿真调用关闭；知识问答MCP已归独立项目，不是第3章默认依赖。

通过正常DSH profile验证实际工具目录，新增插件使用insert语法；修改已有config须保留所需字段。模型密钥放Linux私有配置，不打印、不提交Git。真实模型鉴权及单小算例验收本轮不执行。计算型后处理和全部仿真仍只走超算调度节点。
