# DSH自进化研究入口

概括研究定位与章节边界见[第4章共享设计](../../../graduation-thesis-materials/graduation-research/chapters/chapter04.md)，整篇论文关系见[总体设计](../../../graduation-thesis-materials/graduation-research/OVERVIEW.md)。本目录维护详细工程与实验计划，共享设计通过链接引用本计划，不复制协议细节。

研究问题、对照条件、题集隔离、独立评分、版本冻结与实施顺序见[PLAN.md](PLAN.md)。当前只有设计，尚未实现自进化控制器或产生DSH正式收益结果。

本目录独立研究基于DSH的单agent递归自改进（RSI）。同一agent承担任务执行、自诊断与自身改进；确定性验证器及统计程序不计为agent。不加载第3章多角色bundle，不依赖第3章轨迹或产物契约。经验技能、候选插件及运行结果按版本保存在外部`chapter4_self_evolution/dsh/`实验归档，最终论文图件进入`graduation-thesis-materials/graduation-manuscript/assets/chapter4/`。
