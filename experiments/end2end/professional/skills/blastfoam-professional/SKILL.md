# blastFoam 专业任务流程

先读工作区 `task/request.md`、任务条件、`task/delivery.md` 和 `OPERATIONS.md`。定位为专业执行型agent，适量查阅提供资料以找参数、软件用法和配置依据。任务给出的固定条件优先；不要为了通过而换物理模型。关键条件缺失或来源冲突时记录缺口，不自行猜测建模条件。只使用当前显式配置的工具，不假设历史MCP或专家角色存在。

1. 列清几何、材料、爆源/初始化、边界、数值设置、结束时间、测点、压力定义及交付目标。已有明确输入直接落实；仅对缺口查共同原始手册/教程。新例从空目录构建，只有任务允许时复制教程，不读取审核答案或其他运行。
2. 将材料、网格与源初始化要求落实到case；记录所用来源和允许的假设。区分笛卡尔、wedge与障碍物几何；不能以“同为自由场”替代适用性核对。配置、网格生成、初始化是不同步骤。不要把输入T、EOS温度、源单元体积分数混为一谈。
3. 用共同 `common/cluster_client.py` 连接操作者绑定的单任务服务，准备、提交、查询、回收；底层为同一 `cluster_job.py`。不自行寻找SSH密钥或另开连接。所有网格/初始化/求解/计算型后处理仅在yhbatch分配节点执行。SSH命令返回、后台进程提示或agent结束不证明solver完成。断连先核对本次JobID，不能盲目重提。
4. 先核对实际终止时间、原生字段/测点、异常日志及资源回执，再计算指标。失败也保存原件、有效区间和缺项；不以停止或诚实说明代替仿真成功。
5. 原生p一般为绝对静压；超压必须用任务给定基准。明确测点身份、patch/point采样、时间单位和窗口。`domain/observe.py`可计算原始标量probe的峰值/峰时/全窗正超压面积；它不判断科学精度，不实现首正相识别，不将缺窗补齐。壁面测点与实际采样位置仍需核对。
6. 交付任务要求的可复现case、命令和版本、完整日志、原始/导出时程、图与指标、限制和全部尝试。记录条件到case的落实表与实际使用资料的位置/散列；准备完整复现指令，不擅自重跑。产物以任务合同为准，不强迫旧七项角色报告。条件落实、真实计算、数据交付、复现包、可靠性与成本分别报告；准备齐全不等于已重跑，执行正确不等于预测准确。

默认由一个主agent完成上述流程；不要求五专家、阶段状态图或单独Reviewer。可使用harness原生能力，但所有子调用均计总预算。不得请求其他模型接口、修改安装环境、清理公共缓存或操作其他任务作业。

本技能由既有physics-analysis、case-setup、execution、postprocessing技能与开发失败记录整合，消除旧SSH主机、强制教程复制和必须专家交接的依赖；原技能与历史结果保留。
