---

在提交前写好离散化源码、独立后处理和 README 的复跑命令。逐项核对压力下降率与轴向坐标的约定、壁面条件、对称轴控制体，以及矩阵行的符号和尺度。共同客户端的专业扩展会检查单调扩散格式的驱动方向。若检查报告矛盾，在自己的源码中回到控制方程核对，重新生成输入再提交。客户端不改输入。

collect 会核验节点上传入的矩阵与回传速度表。将原生速度表和回执复制到交件内，在交件目录调用后处理，写出表中中心速度与积分流量。按 README 从干净目录重建输入和读出，保留核验依据。如果同一检查连续得到相同结果，保存该结果、记录结论并完成其余交件。
