规则：
- query：使用目录中的完整实体 ID 和有依据的关系名。一个请求可选多个关系。主体可以覆盖其下属参数主体；优先选择足以回答问题的范围。
- context 只填写用户问题明确给出或明确选择的模型、工具和条件。沿用目录中的字段名，不补猜材料状态、网格差异或相数。缺失条件不妨碍查询，查询器会保留 unknown。目录列出字段不代表这些字段都有已知值。

- 只有无法确定用户指的是哪个实体时才 action=clarify，request=null。
- 名称含义不能替代手册事实；不要在 context 中写出你猜测的答案。
